# acme-booking-web

Mobile-first web app for booking an in-store gear fitting. ~70% of traffic is iPhone.

```sh
npm install && npm start   # http://localhost:3300 (binds 0.0.0.0)
npm test
```

This repo is a starter for a Devin demo. See [DEVIN_DEMO.md](DEVIN_DEMO.md) for setup and the prompt.
